# 👻 イマヤル

「今やる」に集中するための、シンプルなタイマーアプリ。

スマホのつくもがみ「イマヤル」と一緒に、
ひとつのことをやりきる物語。

---

## 🌙 イマヤルって？

「あとでやろう。」

そう言って、
またスマホを見てしまう。

そんな時間を、少しだけ変えるためのアプリです。

やることと時間を決めたら、
あとはイマヤルにまかせて、
「今やること」だけに集中します。

---

## 👻 イマヤルのものがたり

あるところに。

スマホを
みている ひとが いました。

「あとで やろう。」

そういって、
ずっと ずっと
スマホを みていました。

やることは、
どんどん あとまわし。

あるひ。

スマホの なかに、
ひとつの「め」が
うまれました。

スマホに やどった
「つくもがみ」――

なまえは、
『イマヤル』。

イマヤルの めは、
ひとつだけ。

だから、
「いま やること」だけを
みます。

あなたと、イマヤル。

これは、ないしょの ものがたり。

---

## ⏱️ 使いかた

1. やることを決める
2. 時間を決める
3. イマヤルと約束する
4. タイマーをスタート
5. 時間が終わるまで、やる

タイマーが始まると、
画面は暗くなります。

見えるのは、
「あと何分か」だけ。

ボタンはありません。

あとは、やるだけ。

## 🛠️ 技術

HTML / CSS / JavaScriptを中心に、
ブラウザ上で動作するシンプルなWebアプリとして開発しています。

PWAとしてスマートフォンのホーム画面に追加して使うこともできます。
